# HR Analytics Dashboard | Tableau

An interactive HR analytics dashboard built with Tableau Public to explore employee attrition, workforce distribution, job satisfaction, and employee demographics.

## 🔗 Live Interactive Dashboard

**[Explore the Dashboard on Tableau Public](https://public.tableau.com/app/profile/sachin.parmar8573/viz/First_Tableau_project_sachin_parmar/HRANALYTICSDASHBOARD?publish=yes)**

## 📊 Dashboard Overview

This dashboard brings together multiple HR metrics and visualizations to support exploratory workforce analysis.

### Key Metrics
- **Total Employees:** 1,470
- **Attrition Count:** 237
- **Attrition Rate:** 16.1%
- **Active Employees:** 1,233
- **Average Employee Age:** 37

### Dashboard Features
- Department-wise attrition analysis
- Employee distribution by age group
- Job satisfaction ratings across job roles
- Education field-wise attrition
- Attrition by gender and age group
- Interactive education filter and age-bin controls
